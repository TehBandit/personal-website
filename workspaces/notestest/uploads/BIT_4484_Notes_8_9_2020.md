Earned Value Management

Measures project performance based on scope, schedule, and cost

Planned Value (PV)- Portion of approved total cost estimate that was planned to have been spent during a given period

Actual Costs (AC) - Total costs that were actually incurred

Rate of Performance (RP) - Amount of work completed as a proportion of work expected to be completed at given time

Earned Value (EV) - Estimate of the value of work performed in given period



Calculations

Cost Variance (CV) - Compared budgeted cost vs actual costs



Schedule Variance (SV) - Compared work performed vs actual work performed 

SV = EV - PV

Cost Performance Index - Financial effectiveness of a project

CPI = EV / AC

> 1 is good

Schedule Performance Index - How close the project is to schedule

SPI = EV / PV

> 1 is good

Estimate at Completion - Best guess for how much money will be spent at the end of the project
